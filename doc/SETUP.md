# Setup from Samsung A05
1. Upload the folder to a private GitHub repository.
2. Deploy the Docker service on an always-on cloud host.
3. Set METAAPI_TOKEN, METAAPI_ACCOUNT_ID and APP_KEY; keep ENABLE_LIVE=false.
4. Open the deployed URL on the phone.
5. Enter APP_KEY, choose pair, lot size and DEMO, then SAVE and START.
6. Verify account, chart, positions, history and strategy confirmations.
7. Only after demo validation should LIVE execution be enabled server-side.
No desktop bridge is required.
